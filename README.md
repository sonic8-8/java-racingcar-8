**구현 기능**

- 사용자로부터 자동차 이름을 입력 받을 수 있다.

- 사용자로부터 시도할 횟수를 입력 받을 수 있다.

- 사용자가 잘못된 값을 입력할 경우 IllegalArgumentException을 발생 후 애플리케이션이 종료된다.

- 사용자로부터 시도할 횟수로 0을 입력받은 경우, 재입력 받는다.

- 자동차 이름이 중복됐을 경우, 재입력 받는다.

- 자동차 이름에 공백이 들어갈 경우, 재입력 받는다.

- 레이싱 카의 전체 실행 흐름을 제어하는 기능 추가

- 여러 대를 입력 받을 경우, 자동차 이름을 쉼표로 구분하고 객체를 만들어 관리한다.

- 자동차 이름이 5 자를 초과할 경우 IllegalArgumentException이 발생한다.

- 매 차수마다 0에서 9 사이의 랜덤값을 생성하고, 만약 4 이상이라면 전진한다.

- 매 치수마다 0에서 9 사이의 랜덤 값을 생성하고, 만약 3 이하라면 멈춘다.

- 매 차수마다 각 자동차의 라운드 결과를 출력한다.

- 자동차 경주 게임 완료 후, 우승자가 한 명이라면 단독 우승자 문구를 출력한다.

- 자동차 경주 게임 완료 후, 우승자가 여러 명일 경우 우승자의 이름을 쉼표로 구분해 공동 우승자 문구를 출력한다.
